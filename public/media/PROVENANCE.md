# Asset provenance

`archive-corridor.png` is an AI-generated fictional archival illustration, created with the built-in imagegen tool on 2026-09-20. It does not depict a verified historical room in Tworki. The game explicitly labels the fictional archive and illustration.

Prompt: Create one cinematic archival photograph background for a FICTIONAL Polish psychological horror game set in an abandoned institutional hospital basement in 1944, not a real documentary photograph. Landscape 16:9. An empty long decaying hospital corridor with plaster walls, peeling dark institutional paint, heavy old doors with observation slots, a single empty metal treatment chair in the near foreground right, old ceiling lamps, dust in a dim shaft of light, distant doorway swallowed in black. Sepia black-and-white silver gelatin photographic texture, subtle damaged film grain, authentic period objects, sophisticated ominous composition, detailed realistic textures, readable midtones with deep blacks. No people, no gore, no Nazi symbols, no modern equipment, absolutely no lettering or text or watermarks. Used behind animated fictional case files; leave lower left dark and relatively uncluttered.

`../audio/*.mp3` are synthetic neural voice recordings generated with Coqui XTTS-v2 in Polish. The archive narrator uses the built-in `Viktor Menelaos` speaker embedding; radio/gameplay lines use `Zofija Kendrick`. Files are gently mastered with FFmpeg while the game applies only light archive/radio/spatial filtering at runtime. Texts are in `../audio/transcript.json`, regeneration script in `scripts/generate-voices.py`. These are synthetic voices, not recordings or imitations of named actors.

`../audio/music/abandoned-passages.ogg` is **Abandoned passages (horror ambience loop)** by congusbongus from OpenGameArt, licensed CC0. Source: https://opengameart.org/content/abandoned-passages-horror-ambience-loop

`../audio/music/lurking-evil.ogg` is **A lurking evil (horror ambience)** by congusbongus from OpenGameArt, licensed CC0. Source: https://opengameart.org/content/a-lurking-evil-horror-ambience

Game material textures, doctor geometry, document animation and incidental noise sounds are generated by project code.
